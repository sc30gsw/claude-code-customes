# Debug Error Command

## 概要

Serena MCPを統合した高度なデバッグシステム。インテリジェントなコードベース分析とエラー解決を提供します。

## 基本情報

| 項目 | 値 |
|------|-----|
| コマンド | `/debug-error` |
| 引数 | `<error_description>` または `<file:line>` |
| 用途 | エラー診断、根本原因分析 |
| 許可ツール | すべてのツール |

## 主要機能

### 1. エラー分析
- スタックトレースの解析
- エラーメッセージのパターン認識
- 関連コードの自動特定

### 2. コードフロートレース
- Serenaのシンボル検索を活用
- 依存関係の追跡
- 実行パスの可視化

### 3. パターン検索
- 類似エラーの履歴検索
- 共通の失敗パターンの特定
- 修正履歴の参照

### 4. メモリ統合
- 以前のデバッグセッションの参照
- 学習した修正パターンの適用
- プロジェクト固有の知識活用

## 使用例

```bash
# エラーメッセージでデバッグ
/debug-error "TypeError: Cannot read property 'map' of undefined"

# ファイルと行番号で特定
/debug-error src/components/List.tsx:45

# スタックトレースを貼り付けて分析
/debug-error [paste full stack trace]
```

## デバッグプロセス

1. **エラー情報の収集** - メッセージ、スタックトレース、コンテキスト
2. **関連コードの特定** - Serenaでシンボルと参照を検索
3. **根本原因の分析** - コードフローとデータフローを追跡
4. **修正案の提案** - 複数の解決アプローチを提示
5. **修正の適用** - 承認後に変更を実装

## Serena MCP統合

- **find_symbol**: シンボル定義の検索
- **find_referencing_symbols**: 参照箇所の特定
- **search_for_pattern**: パターンベースの検索
- **メモリ機能**: デバッグコンテキストの保存

## ベストプラクティス

1. **完全なエラー情報を提供** - スタックトレース全体を含める
2. **再現手順を明記** - エラー発生条件を説明
3. **環境情報を含める** - Node.jsバージョンなど
4. **段階的に修正** - 一度に1つの問題を解決
