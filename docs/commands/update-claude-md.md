# Update CLAUDE.md Command

## 概要

SerenaとSequential Thinkingを統合したインテリジェントなCLAUDE.md自動生成・更新コマンド。プロジェクト固有の設定を維持しながら最新の状態に保ちます。

## 基本情報

| 項目 | 値 |
|------|-----|
| コマンド | `/update-claude-md` |
| 用途 | CLAUDE.mdの生成・更新 |
| 許可ツール | すべてのツール |

## 主要機能

### 1. 自動検出
- プロジェクト構造の分析
- 技術スタックの特定
- 既存のルールとパターンの検出

### 2. インテリジェント更新
- 既存設定の保持
- 新しいパターンの追加
- 非推奨項目のマーク

### 3. Serena統合
- シンボル構造の分析
- コーディングパターンの抽出
- プロジェクトメモリの活用

### 4. Sequential Thinking
- 段階的な分析プロセス
- 包括的な設定生成
- 品質チェック

## 使用例

```bash
# CLAUDE.mdの生成/更新
/update-claude-md

# 特定セクションのみ更新
/update-claude-md --section rules

# ドライラン（変更プレビュー）
/update-claude-md --dry-run
```

## 生成されるセクション

### プロジェクト情報
- プロジェクト名と説明
- 技術スタック
- ディレクトリ構造

### コーディングルール
- スタイルガイドライン
- 命名規則
- パターンと規約

### 開発ワークフロー
- ビルドコマンド
- テスト実行方法
- デプロイ手順

### カスタム設定
- プロジェクト固有のルール
- 特殊な要件
- チーム規約

## 更新プロセス

1. **現在の状態を読み取り** - 既存のCLAUDE.mdを解析
2. **プロジェクト分析** - Serenaでコードベースを調査
3. **差分の検出** - 変更が必要な項目を特定
4. **インテリジェント更新** - 保持/追加/更新を判断
5. **検証** - 生成された設定の整合性チェック

## 出力形式

```markdown
# CLAUDE.md

## プロジェクト概要
[自動生成された概要]

## 技術スタック
- Frontend: React, TypeScript
- Backend: Node.js, Express
- Database: PostgreSQL

## コーディングルール
[検出されたパターンに基づくルール]

## 開発コマンド
[プロジェクトのスクリプトから抽出]
```

## ベストプラクティス

1. **定期的な更新** - 大きな変更後に実行
2. **カスタム設定の保護** - 手動追加した内容を維持
3. **変更のレビュー** - 自動生成結果を確認
4. **バージョン管理** - 更新履歴を追跡
