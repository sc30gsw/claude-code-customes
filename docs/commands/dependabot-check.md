# Dependabot Check Command

## 概要

Dependabotセキュリティアドバイザリーを分析し、解決戦略を提供するコマンド。脆弱性の評価と修正計画の策定を支援します。

## 基本情報

| 項目 | 値 |
|------|-----|
| コマンド | `/dependabot-check` |
| 引数 | `<advisory_url>` または `<package_name>` |
| 用途 | セキュリティ脆弱性の分析と解決 |
| 許可ツール | Bash, Read, WebFetch, WebSearch |

## 主要機能

### 1. アドバイザリー分析
- CVE詳細の取得
- 影響範囲の特定
- 重大度の評価（Critical/High/Medium/Low）

### 2. 依存関係の調査
- 直接依存 vs 推移的依存の識別
- 影響を受けるコードパスの特定
- 代替パッケージの検索

### 3. 解決戦略の策定
- バージョンアップグレードの提案
- 互換性の検証
- マイグレーションパスの計画

### 4. リスク評価
- 実際の攻撃可能性の分析
- 緩和策の提案
- 優先度付けの支援

## 使用例

```bash
# アドバイザリーURLで分析
/dependabot-check https://github.com/advisories/GHSA-xxxx-xxxx-xxxx

# パッケージ名で検索
/dependabot-check lodash

# 現在の脆弱性をすべて確認
/dependabot-check --all
```

## 出力形式

```markdown
## セキュリティアドバイザリー分析

### 概要
- **パッケージ**: [name]@[version]
- **重大度**: [Critical/High/Medium/Low]
- **CVE**: CVE-XXXX-XXXXX

### 影響分析
- 影響を受けるコードパス
- 攻撃ベクトル
- 実際のリスク評価

### 解決戦略
1. 推奨: [アップグレード/パッチ/代替]
2. 具体的な手順
3. 互換性に関する注意点

### 検証計画
- テスト項目
- 確認手順
```

## ベストプラクティス

1. **Critical/Highを優先** - 重大度の高い脆弱性を先に対処
2. **テスト環境で検証** - 本番適用前に互換性を確認
3. **依存関係ツリーを確認** - 推移的依存の影響を把握
4. **定期的なスキャン** - 新しい脆弱性を早期発見
