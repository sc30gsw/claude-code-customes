# /update-docs - ドキュメント更新コマンド

---
description: ソースオブトゥルースからドキュメントを同期
---

## 概要

`/update-docs` コマンドは **doc-updater** エージェントを呼び出し、コードベースの信頼できる情報源からドキュメントを同期します。

## 機能

1. package.jsonのscriptsセクションを読み取り
2. .env.exampleから環境変数を抽出
3. 開発ドキュメントを生成
4. 運用ドキュメントを生成
5. 古いドキュメントを特定
6. 差分サマリーを表示

## 動作フロー

### 1. package.jsonスクリプトの読み取り

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "test": "jest"
  }
}
```

↓ 変換

```markdown
| Script | Command | Description |
|--------|---------|-------------|
| dev | next dev | 開発サーバー起動 |
| build | next build | 本番ビルド |
| test | jest | テスト実行 |
```

### 2. .env.exampleから環境変数抽出

```bash
# .env.example
DATABASE_URL=postgresql://...
API_KEY=your-api-key
```

↓ 変換

```markdown
| Variable | Description | Required |
|----------|-------------|----------|
| DATABASE_URL | データベース接続URL | Yes |
| API_KEY | APIキー | Yes |
```

### 3. docs/CONTRIB.md生成

以下を含む:
- 開発ワークフロー
- 利用可能なスクリプト
- 環境セットアップ
- テスト手順

### 4. docs/RUNBOOK.md生成

以下を含む:
- デプロイ手順
- 監視とアラート
- 一般的な問題と修正
- ロールバック手順

### 5. 古いドキュメントの特定

```
90日以上更新されていないドキュメント:
- docs/old-feature.md (120 days)
- docs/deprecated-api.md (95 days)

→ 手動レビューが必要
```

### 6. 差分サマリー表示

```markdown
# ドキュメント更新サマリー

## 更新されたファイル
- docs/CONTRIB.md - スクリプト追加: 3
- docs/RUNBOOK.md - 手順更新: 2

## 新規作成
- docs/env-variables.md

## 古いドキュメント（要レビュー）
- docs/old-feature.md
```

## 信頼できる情報源

| ドキュメント | ソース |
|-------------|--------|
| スクリプトリファレンス | package.json |
| 環境変数 | .env.example |
| API仕様 | コード内のJSDoc |
| セットアップ手順 | 実際のコマンド出力 |

## ベストプラクティス

1. **単一の信頼源** - 手動で書かず、コードから生成
2. **更新タイムスタンプ** - 常に最終更新日を含める
3. **実行可能** - 実際に機能するセットアップコマンドを含める
4. **リンク付き** - 関連ドキュメントを相互参照
5. **例付き** - 実際に動作するコードスニペットを表示
6. **バージョン管理** - ドキュメント変更をgitで追跡

## 品質チェックリスト

ドキュメントコミット前に確認:
- [ ] コードマップが実際のコードから生成されている
- [ ] すべてのファイルパスが存在確認済み
- [ ] コード例がコンパイル/実行される
- [ ] リンクがテスト済み（内部と外部）
- [ ] 更新タイムスタンプが更新されている
- [ ] 廃止された参照がない
- [ ] スペル/文法がチェック済み

## 使用タイミング

以下の場面で使用:
- 新しい主要機能追加後
- APIルート変更後
- 依存関係追加/削除後
- セットアッププロセス変更後
- リリース前のドキュメント監査

## 他のコマンドとの連携

- `/update-codemaps` でコードマップを更新

## 関連エージェント

このコマンドは以下のエージェントを呼び出します:
`~/.claude/agents/doc-updater.md`

## 重要な注意事項

**Remember**: 現実と一致しないドキュメントはドキュメントがないよりも悪い。常に信頼源（実際のコード）から生成してください。
