# Chrome Command

## 概要

Chrome DevToolsとAI駆動の分析を統合した包括的なブラウザ開発システム。E2Eテスト、パフォーマンスプロファイリング、デバッグ、ブラウザ自動化に対応します。

## 基本情報

| 項目 | 値 |
|------|-----|
| コマンド | `/chrome` |
| 用途 | ブラウザ開発、E2Eテスト、パフォーマンス分析 |
| 許可ツール | すべてのツール |

## 主要機能

### 1. E2Eテスト
- ユーザージャーニーの自動テスト
- クロスブラウザ互換性検証
- スクリーンショット・動画キャプチャ
- アクセシビリティテスト

### 2. パフォーマンス分析
- ページ読み込み時間の計測
- Core Web Vitals（LCP、FID、CLS）の測定
- ネットワークリクエスト分析
- メモリ使用状況のプロファイリング

### 3. デバッグ
- コンソールメッセージの監視
- ネットワークリクエストの検査
- DOM要素のインスペクション
- JavaScriptエラーの追跡

### 4. ブラウザ自動化
- フォーム操作の自動化
- ナビゲーションフローの実行
- ダイアログ処理
- ファイルアップロード

## 使用例

```bash
# E2Eテストの実行
/chrome test-login-flow

# パフォーマンス分析
/chrome analyze-performance https://example.com

# スクリーンショット撮影
/chrome screenshot full-page

# コンソールメッセージの確認
/chrome console-errors
```

## MCP統合

- **chrome-devtools MCP**: ネイティブChrome DevTools機能
- **Playwright MCP**: E2Eテストフレームワーク

## ベストプラクティス

1. **テストシナリオの明確化** - ユーザーフローを事前に定義
2. **パフォーマンスベースラインの設定** - 測定基準を明確に
3. **エラーハンドリング** - ダイアログやタイムアウトに対応
4. **アーティファクトの保存** - スクリーンショット・トレースを保存
