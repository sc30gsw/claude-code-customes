# /test-coverage - テストカバレッジコマンド

---
description: テストカバレッジを分析し、不足しているテストを生成
---

## 概要

`/test-coverage` コマンドはテストカバレッジを分析し、カバレッジが不足している部分に対してテストを生成します。

## 機能

1. カバレッジ付きでテスト実行
2. カバレッジレポートを分析
3. 80%閾値以下のファイルを特定
4. 不足テストを生成
5. 新規テストが通過することを確認
6. 前後のカバレッジ指標を表示

## 動作フロー

### 1. カバレッジ付きテスト実行

```bash
npm test --coverage
# または
pnpm test --coverage
```

### 2. カバレッジレポート分析

`coverage/coverage-summary.json` を分析

### 3. カバレッジ不足ファイルの特定

80%閾値以下のファイルをリストアップ

### 4. 各ファイルに対してテスト生成

```
- 未テストのコードパスを分析
- 関数のユニットテストを生成
- APIの統合テストを生成
- クリティカルフローのE2Eテストを生成
```

### 5. テスト検証

新規テストが通過することを確認

### 6. カバレッジ指標表示

```
Before:
File           | % Stmts | % Branch | % Funcs | % Lines
---------------|---------|----------|---------|--------
auth.ts        |   45    |   30     |   40    |   45
utils.ts       |   60    |   50     |   55    |   60
Overall        |   52    |   40     |   47    |   52

After:
File           | % Stmts | % Branch | % Funcs | % Lines
---------------|---------|----------|---------|--------
auth.ts        |   92    |   85     |   90    |   92
utils.ts       |   88    |   82     |   85    |   88
Overall        |   90    |   83     |   87    |   90

✅ Project now at 90% coverage (target: 80%)
```

## テスト対象

### ハッピーパスシナリオ
- 正常な入力での期待される動作
- 成功時の戻り値
- 正常なフロー

### エラーハンドリング
- 例外がスローされるケース
- エラーメッセージの検証
- リカバリー動作

### エッジケース
- null, undefined, 空の値
- 境界値（0, 負数, 最大値）
- 特殊文字、長い文字列

### 境界条件
- 配列の最初と最後の要素
- ページネーションの境界
- タイムアウト条件

## カバレッジ要件

| コードタイプ | 最小カバレッジ |
|-------------|--------------|
| 通常のコード | 80% |
| 金融計算 | 100% |
| 認証ロジック | 100% |
| セキュリティクリティカル | 100% |
| コアビジネスロジック | 100% |

## 出力例

```markdown
# テストカバレッジレポート

## サマリー
- 全体カバレッジ: 90%
- 目標達成: ✅ YES

## 改善されたファイル

- Before: 45%
- After: 92%
- 追加テスト: 8

### src/utils/format.ts
- Before: 60%
- After: 88%
- 追加テスト: 5

## 生成されたテストファイル
- src/auth/login.test.ts (8 tests)
- src/utils/format.test.ts (5 tests)
```
