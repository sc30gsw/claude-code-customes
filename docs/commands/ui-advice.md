# UI Advice Command

## 概要

UI/UXデザインパターンのアドバイスとテキストワイヤーフレームを生成するコマンド。設計段階での意思決定を支援します。

## 基本情報

| 項目 | 値 |
|------|-----|
| コマンド | `/ui-advice` |
| 引数 | `<component_or_feature>` |
| 用途 | UIデザインアドバイス、ワイヤーフレーム生成 |
| 許可ツール | Read, Write, WebSearch |

## 主要機能

### 1. デザインパターンアドバイス
- 一般的なUIパターンの推奨
- アクセシビリティガイドライン
- レスポンシブデザイン考慮

### 2. テキストワイヤーフレーム
- ASCIIベースのレイアウト提案
- コンポーネント配置の可視化
- インタラクションフローの説明

### 3. ベストプラクティス
- ユーザビリティ原則
- デザインシステム統合
- パフォーマンス考慮

## 使用例

```bash
# コンポーネントのアドバイス
/ui-advice "data table with sorting and filtering"

# ページレイアウトの提案
/ui-advice "dashboard layout for analytics"

# フォームデザイン
/ui-advice "multi-step registration form"
```

## 出力形式

### デザインアドバイス
```markdown
## UIパターン推奨

### レイアウト
- グリッドシステムの使用
- 適切な余白とスペーシング

### インタラクション
- ホバー状態の定義
- フィードバックの提供

### アクセシビリティ
- キーボードナビゲーション
- スクリーンリーダー対応
- コントラスト比の確保
```

## ベストプラクティス

1. **ユーザー中心** - ユーザーニーズを優先
2. **一貫性** - デザインシステムに従う
3. **アクセシビリティ** - WCAG基準を満たす
4. **パフォーマンス** - 読み込み時間を考慮
