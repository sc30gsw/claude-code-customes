# 環境変数

> 出典: [Claude Code 公式ドキュメント（環境変数）](https://code.claude.com/docs/ja/env-vars)

私が設定しているのは以下の3つ。

---

## 1. `ENABLE_TOOL_SEARCH`

### 何を
Claude Code既製の環境変数。MCPツールの**事前読み込み（eager loading）vs 遅延読み込み（defer loading）**を制御する。

### どの作業のために
MCPサーバーを複数つないでいると、ツール定義だけでコンテキストウィンドウを大量に消費する。この変数で「必要になった時だけツール定義を検索・ロードする」挙動（MCP tool search）に切り替え、コンテキストを節約する。

### 取りうる値

| 値 | 挙動 |
|---|---|
| 未設定（デフォルト） | 全MCPツールを遅延読み込み。ただし例外あり：Google CloudのAgent Platform（Claude 4.5世代より前のモデル）、`ANTHROPIC_BASE_URL`が非ファーストパーティホストを指す場合、AzureのMicrosoft Foundryデプロイでは事前読み込み |
| `true` | 常に遅延読み込み＋ベータヘッダー送信。ただしAzure Foundry・Agent Platformの旧世代モデルでは事前読み込みのまま。`tool_reference`非対応プロキシではリクエスト失敗 |
| `auto` | 閾値モード。ツール定義がコンテキストの10%以内に収まるなら事前読み込み |
| `auto:N` | カスタム閾値（例: `auto:5`で5%） |
| `false` | 全ツールを常に事前読み込み |

### 注意点
- `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` が設定されていると **`ENABLE_TOOL_SEARCH` は無視され**、全ツール事前読み込みになる
- バージョン経緯: **v2.1.119**でVertex AI（Google CloudのAgent Platform）上のツール検索がデフォルト無効化され（ベータヘッダー非対応エラー回避のため）、**v2.1.221**でClaude 4.5世代以降のモデルのみ再有効化された。それより前は `true` を明示しない限り全モデルで無効だった（出典: [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) v2.1.119 / v2.1.221）
- ⚠️ このバージョン注記は**英語版ドキュメントにのみ記載**（日本語版は未反映、2026-08-10時点）。一次ソースは英語版を参照

### 入れる前と後（③・実体験）
私の実設定は **`true`**。
- **前**: MCPツール定義が全部コンテキストに展開され、セッション開始時点で数万トークン消費
- **後**: ツール定義は必要時ロード。MCPを複数つないでもコンテキストが痩せない。プロキシ環境では失敗リスクがあるので値の選択が重要

## 2. `CLAUDE_CODE_NEW_INIT`

### 何を
Claude Code既製の環境変数。`/init` コマンドを**対話的セットアップフロー**に変える。

### どの作業のために
新規プロジェクトのオンボーディング。CLAUDE.mdだけでなく、スキル・フックまで含めて「何を生成するか」を対話で選びながらセットアップしたい時。

### 挙動
- **未設定（デフォルト）**: `/init` は確認なしで自動的にCLAUDE.mdを生成
- **`=1`**: `/init` が「どのファイルを生成するか（CLAUDE.md・スキル・フック等）」を先に質問 → その後コードベースを探索して書き込む

### 入れる前と後
- **前**: `/init` 一発でCLAUDE.mdが自動生成されるだけ。スキルやフックは手作業で別途作成
- **後**: 生成物を取捨選択でき、プロジェクトに合ったスキル・フックまで一度に整う。初期セットアップの手作業が減る

---

## 3. `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`

### 何を
Claude Code既製の環境変数。実験的機能「**エージェントチーム（Agent Teams）**」を有効化する。

### どの作業のために
複数のサブエージェントがチームとして協調動作する機能を使うため。大きめのタスクを並列・分担で進めたい時の布石。

### 挙動
- `1` に設定するとエージェントチームが有効化される
- **実験的機能でデフォルト無効**。詳細仕様は[公式のagent-teamsページ](https://code.claude.com/docs/ja/agent-teams)参照

### 入れる前と後
- **前**: 機能自体が存在しない（サブエージェントは個別起動のみ）
- **後**: チーム単位のマルチエージェント協調が使える。**Fable 5をオーケストレーターとして簡単に使える**のが個人的な推しポイント

---

## まとめ（発表用ワンライナー）

| 環境変数 | 一言で |
|---|---|
| `ENABLE_TOOL_SEARCH` | MCPツール定義の遅延ロードでコンテキスト節約 |
| `CLAUDE_CODE_NEW_INIT` | `/init` を対話式にしてスキル・フックまで一括セットアップ |
| `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` | 実験的マルチエージェントチーム機能の解禁 |
