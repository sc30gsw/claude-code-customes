# よく使う標準コマンド

> 出典: [Claude Code 公式ドキュメント（コマンド）](https://code.claude.com/docs/en/commands)

Claude Code既製のコマンド。やりたいことに合わせて使い分けている。

> **伝えたいこと（発表のテーゼ）**: 開発で必要になる要求の大半は、プラグインを足す前に**Claude Codeのデフォルトのコマンド・設定・環境変数だけで満たせる**。まず標準機能を知り尽くすのが最短ルート。

---

## セットアップ・診断系

### `/init`
プロジェクトに `CLAUDE.md` を初期生成する。`CLAUDE_CODE_NEW_INIT=1` を設定していると対話式フローになり、スキル・フック・個人メモリまで確認しながら生成される（→ [01-environment-variables.md](01-environment-variables.md)）。他のコーディングエージェントの設定を見つけると `/import` での引き継ぎも提案してくれる。

### `/doctor`（エイリアス: `/checkup`）
セットアップ診断・自動修復。重複インストール・PATH問題・壊れた設定ファイルの検出に加え、**未使用のスキル/MCP/プラグインとそのコンテキストコスト**、遅いフック、新バージョンの有無まで確認する。常時読込のCLAUDE.mdを必要時読込のスキルへ移す提案までしてくれる。動作がおかしい時・セットアップを痩せさせたい時に。

### `/team-onboarding`
過去30日の自分の利用履歴（セッション・コマンド・MCP使用状況）を解析し、**チームメイトがそのまま貼り付けて使えるオンボーディングガイド**をMarkdownで生成。共有リンクも発行される。今回のような「使い方共有」にもそのまま役立つ。

---

## モデル・出力制御系

### `/model`
モデル切り替え＋新規セッションのデフォルト保存。対応モデルでは左右キーでeffortも調整可。`s` キーでセッション限定切り替え。

### `/effort`
思考努力レベル（`low`〜`max`、`ultracode`）の設定。応答途中でも即座に反映される。「軽いタスクはlow、設計判断はhigh以上」のように精度とコスト・速度のバランスを取る。

### `/advisor`
重要な局面で**第二のモデルにセカンドオピニオンを求める**アドバイザー機能のON/OFF。`opus`/`sonnet` を指定可能（Fable 5はアドバイザーには指定不可）。

---

## 自律実行系

### `/goal`
**ゴール条件を設定すると、達成まで複数ターンにわたってClaudeが作業を継続する**。`clear` で解除。長時間の自律タスクに。
（個人的な感想：Codexの `goal` コマンドが全LLM中最強だと思っているが、Claude Codeのこれも同系統の機能）

### `/loop`（エイリアス: `/proactive`）
プロンプトを繰り返し実行。`/loop 5m check if the deploy finished` のように間隔指定、省略するとClaudeが自分でペースを決める。デプロイ監視・定期チェックに。

### `/deep-research`
質問に対してWeb検索をファンアウトし、複数ソースを取得・相互検証した上で**引用付き調査レポートを合成**するワークフロー。込み入った調査に。

---

## レビュー系

### `/code-review`（エイリアス: `/review`）
現在のdiff / PR番号 / ブランチ / パスを対象にレビュー。
- **`--fix`**: 指摘を自動適用（simplify系のクリーンアップも含む）
- **`--comments`**: GitHub PRへインラインコメント投稿
- `ultra`: クラウドでの深いレビュー（`/ultrareview` 相当）

ローカルレビューはサブエージェントで走るので会話コンテキストを圧迫しない。

### `/ultrareview`
クラウドサンドボックス上の**マルチエージェント深層レビュー**。現在は `/code-review ultra` が推奨呼び出しで、`/ultrareview` はエイリアス。重要な変更の最終チェックに。

---

## セッション管理系

### `/recap`
現在のセッションのワンライン要約をオンデマンド生成。離席復帰時に。

### `/rewind`（エイリアス: `/checkpoint`, `/undo`）
会話やコードを過去時点まで巻き戻すチェックポイント機能。誤った変更の取り消しに。

### `/clear`（エイリアス: `/reset`, `/new`）
空のコンテキストで新しい会話を開始。名前を付けると `/resume` ピッカーでラベル付けされる。コンテキストが肥大化したら躊躇なく切る。

---

## デザイン連携

### `/design-sync`
リポジトリのReactデザインシステムを変換して**Claude Designにアップロード**。以降Claude Designの生成物が自社の実コンポーネントを使うようになる。初回同期は大規模リポジトリだと数時間かかることも。

---

## まとめ（発表用）

| 場面 | コマンド |
|---|---|
| プロジェクト開始 | `/init`（+ `CLAUDE_CODE_NEW_INIT=1`） |
| 精度・コスト調整 | `/model` `/effort` `/advisor` |
| 長時間の自律作業 | `/goal` `/loop` |
| 調査 | `/deep-research` |
| レビュー | `/code-review --fix` / `--comments` / `/ultrareview` |
| セッション整理 | `/recap` `/rewind` `/clear` |
| 健康診断 | `/doctor` |
| チーム展開 | `/team-onboarding` |
| デザイン整合 | `/design-sync` |
