# Build Fix Skill

## 概要

TypeScriptとビルドエラーを段階的に修正し、検証とロールバック機能を備えたスキル。エラーを1つずつ安全に修正し、ビルドの安定性を確保します。

## アクティベーショントリガー

- ビルドが失敗した時
- TypeScriptコンパイルエラーが発生した時
- `npm run build` または `pnpm build` でエラーが出た時
- CI/CDパイプラインでビルドが失敗した時

## コア原則

### 1. 段階的修正
一度に1つのエラーのみを修正し、安全性を確保します。

### 2. 検証サイクル
修正 → 再ビルド → 検証 → 次のエラーへ

### 3. 自動停止条件
- 修正が新しいエラーを引き起こした場合
- 同じエラーが3回連続で修正できない場合
- ユーザーが一時停止を要求した場合

## ワークフロー

### Step 1: ビルド実行
```bash
npm run build
# または
pnpm build
```

### Step 2: エラー出力の解析
- ファイル別にグループ化
- 重要度でソート

### Step 3: エラー修正ループ
1. エラーコンテキストを表示（前後5行）
2. 問題を説明
3. 修正を提案
4. 修正を適用
5. 再ビルド
6. エラー解決を確認

### Step 4: サマリー表示
```markdown
## ビルド修正サマリー

### 修正済み
- src/components/Button.tsx: Type error fixed
- src/utils/helpers.ts: Import error resolved

### 未解決
- src/api/client.ts: Complex type issue

### 新規発生
- None
```

## ベストプラクティス

1. **一度に1つのエラー** - 複数のエラーを同時に修正しない
2. **コンテキスト確認** - 修正前に周辺コードを理解
3. **検証必須** - 修正後は必ずビルドを再実行
4. **ロールバック準備** - 修正が失敗した場合に備える
5. **エラーログ保存** - 将来の参照のためにログを記録

## 成功指標

- ビルドが正常に完了
- 新しいエラーが発生していない
- 全ての型エラーが解消
- テストがパス（存在する場合）
