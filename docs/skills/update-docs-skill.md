# Update Docs Skill

## 概要

package.jsonや.env.exampleなどのソース・オブ・トゥルースファイルからドキュメントを同期するスキル。単一の信頼できる情報源から自動的にドキュメントを生成します。

## アクティベーショントリガー

- ドキュメントの更新が必要な時
- package.jsonのスクリプトが変更された時
- 環境変数が追加・変更された時
- 開発ワークフローのドキュメント化が必要な時

## ワークフロー

### Step 1: package.jsonスクリプトセクションの読み取り
- スクリプト参照テーブルを生成
- コメントからの説明を含める

### Step 2: .env.exampleの読み取り
- 全ての環境変数を抽出
- 目的と形式をドキュメント化

### Step 3: docs/CONTRIB.md生成
```markdown
# コントリビュートガイド

## 開発ワークフロー
...

## 利用可能なスクリプト
| スクリプト | 説明 |
|-----------|------|
| `npm run dev` | 開発サーバー起動 |
| `npm run build` | プロダクションビルド |
...

## 環境設定
...

## テスト手順
...
```

### Step 4: docs/RUNBOOK.md生成
```markdown
# 運用マニュアル

## デプロイ手順
...

## モニタリングとアラート
...

## 一般的な問題と解決策
...

## ロールバック手順
...
```

### Step 5: 古いドキュメントの特定
- 90日以上更新されていないドキュメントを検出
- 手動レビュー用にリスト化

### Step 6: 差分サマリー表示

## 生成ファイル

| ファイル | 内容 |
|----------|------|
| `docs/CONTRIB.md` | 開発ワークフロー、スクリプト、環境設定、テスト |
| `docs/RUNBOOK.md` | デプロイ、モニタリング、トラブルシューティング |

## ソース・オブ・トゥルース

| ソースファイル | 抽出情報 |
|---------------|---------|
| `package.json` | スクリプト、依存関係、バージョン |
| `.env.example` | 環境変数、設定項目 |

## ベストプラクティス

1. **単一ソース** - 情報は1箇所のみに保存
2. **自動同期** - 定期的にドキュメントを更新
3. **古いドキュメント確認** - 90日以上更新のないものを確認
4. **差分確認** - 更新前に変更内容を確認

## 成功指標

- ドキュメントがソースと同期している
- 全スクリプトがドキュメント化されている
- 全環境変数がドキュメント化されている
- 古いドキュメントが特定されている
