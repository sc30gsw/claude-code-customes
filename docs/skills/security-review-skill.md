# Security Review Skill

## 概要

認証機能の実装、ユーザー入力の処理、シークレットの取り扱い、APIエンドポイントの作成、決済機能や機密性の高い機能を実装する際に使用するスキル。包括的なセキュリティチェックリストとパターンを提供します。

## アクティベーショントリガー

- 認証・認可機能の実装時
- ユーザー入力やファイルアップロードの処理時
- 新規APIエンドポイントの作成時
- シークレットや認証情報の取り扱い時
- 決済機能の実装時
- 機密データの保存・送信時
- サードパーティAPIの統合時

## 主要な機能

### 1. シークレット管理
- ハードコードされたシークレットの検出・防止
- 環境変数を使用した適切な管理方法の提示
- `.env.local` のgitignore設定確認

### 2. 入力バリデーション
- Zodスキーマを使用した入力検証パターン
- ファイルアップロードの検証（サイズ、タイプ、拡張子）
- ホワイトリストバリデーションの推奨

### 3. SQLインジェクション防止
- パラメータ化クエリの使用
- ORM/クエリビルダーの正しい使用方法
- Supabaseクエリのサニタイズ

### 4. 認証・認可
- JWTトークンの安全な処理（httpOnlyクッキー）
- 認可チェックの実装パターン
- Row Level Security (RLS) の設定

### 5. XSS防止
- DOMPurifyを使用したHTMLサニタイズ
- Content Security Policy (CSP) の設定
- Reactの組み込みXSS保護の活用

### 6. CSRF保護
- CSRFトークンの実装
- SameSiteクッキーの設定

### 7. レート制限
- APIエンドポイントへのレート制限
- 高コスト操作への厳格な制限

### 8. 機密データ保護
- ログへの機密データ出力防止
- ユーザー向けエラーメッセージの汎化

### 9. ブロックチェーンセキュリティ（Solana）
- ウォレット署名の検証
- トランザクション検証

### 10. 依存関係セキュリティ
- `npm audit` による脆弱性チェック
- ロックファイルのコミット
- Dependabotの有効化

## デプロイ前チェックリスト

- [ ] シークレット: ハードコードなし、全て環境変数
- [ ] 入力バリデーション: 全てのユーザー入力を検証
- [ ] SQLインジェクション: 全クエリがパラメータ化
- [ ] XSS: ユーザーコンテンツをサニタイズ
- [ ] CSRF: 保護が有効
- [ ] 認証: 適切なトークン処理
- [ ] 認可: ロールチェック実装
- [ ] レート制限: 全エンドポイントで有効
- [ ] HTTPS: 本番環境で強制
- [ ] セキュリティヘッダー: CSP、X-Frame-Options設定
- [ ] エラー処理: エラーに機密データなし
- [ ] ログ: 機密データの出力なし
- [ ] 依存関係: 最新、脆弱性なし
- [ ] RLS: Supabaseで有効
- [ ] CORS: 適切に設定
- [ ] ファイルアップロード: 検証済み（サイズ、タイプ）
- [ ] ウォレット署名: 検証済み（ブロックチェーンの場合）
