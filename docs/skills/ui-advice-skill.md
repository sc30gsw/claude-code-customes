# UI Advice Skill

## 概要

UI/UXデザインパターンのアドバイスとテキストワイヤーフレームを提供するスキル。有名なデザインシステムを参照し、要件に適したデザインパターンを推奨します。

## アクティベーショントリガー

- UIデザインのアドバイスが必要な時
- 適切なレイアウトパターンを選択したい時
- ワイヤーフレームでアイデアを視覚化したい時
- デザインの選択肢を比較したい時

## 使用方法

UI/UXの要件を説明すると、スキルが分析してデザインパターンの推奨を提供します。

## 提供内容

### 1. デザインパターン提案
要件に適した3-5のデザインパターンを提案

### 2. パターン説明
各パターンの特徴、メリット/デメリット、ユースケース

### 3. テキストワイヤーフレーム
各パターンのシンプルなASCIIワイヤーフレーム

### 4. 推奨
状況に最も適したパターンの推奨

## 参照デザインシステム

- **Material Design** (Google)
- **Apple Human Interface Guidelines**
- **Ant Design**
- **Mantine** (Context7経由で最新情報取得)

## ガイドライン

- 有名なデザインシステムからパターンを参照
- ユーザビリティ、アクセシビリティ、現在のトレンドを考慮
- シンプルで理解しやすいワイヤーフレームを作成
- 各パターンの実装複雑度を含める
- Mantineを使用する場合はContext7経由で最新コンポーネント情報を取得

## ワイヤーフレームルール

```
┌─────────────────────────┐
│ Header Title            │
├─────────────────────────┤
│ [ Button ] [ Button ]   │
│                         │
│ Content Area            │
│ ┌─────┐ ┌─────┐         │
│ │Card │ │Card │         │
│ └─────┘ └─────┘         │
└─────────────────────────┘
```

シンプルなASCII文字を使用して構造を明確に表現

## デザインパターン例

### レイアウトパターン
- **グリッドレイアウト**: 均等なアイテム表示
- **リストレイアウト**: 詳細情報の表示
- **マスターディテール**: 一覧と詳細の分割
- **ダッシュボード**: 複数のウィジェット配置

### ナビゲーションパターン
- **タブナビゲーション**: カテゴリ切り替え
- **サイドバー**: 階層的なナビゲーション
- **ボトムナビゲーション**: モバイル向け主要機能
- **パンくずリスト**: 階層表示

### 入力パターン
- **ステップフォーム**: 段階的な入力
- **インラインエディット**: その場での編集
- **モーダルフォーム**: フォーカスした入力
- **オートコンプリート**: 入力補助

### フィードバックパターン
- **トースト**: 軽量な通知
- **アラート**: 重要な通知
- **プログレス**: 進捗表示
- **スケルトン**: ローディング状態

## 実装複雑度

| レベル | 説明 | 工数目安 |
|--------|------|---------|
| Low | 標準コンポーネントで実装可能 | 1-2日 |
| Medium | カスタマイズが必要 | 3-5日 |
| High | 複雑なロジックを含む | 1-2週間 |

## ベストプラクティス

1. **ユーザー中心** - ユーザーのニーズを優先
2. **一貫性** - デザインシステムに従う
3. **アクセシビリティ** - すべてのユーザーが使えるように
4. **レスポンシブ** - 様々なデバイスに対応
5. **パフォーマンス** - 高速なインタラクション

## 成功指標

- ユーザーのニーズに合ったパターンを提案
- ワイヤーフレームが理解しやすい
- 実装複雑度が正確に評価される
- デザインシステムとの整合性
- アクセシビリティ要件を満たす
