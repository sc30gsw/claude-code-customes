# Update Codemaps Skill

## 概要

コードベース構造を分析し、差分追跡付きでアーキテクチャドキュメントを更新するスキル。高レベルな構造を把握し、トークン効率の良いコードマップを生成します。

## アクティベーショントリガー

- アーキテクチャドキュメントの更新が必要な時
- コードベース構造が大きく変更された時
- 新しい開発者のオンボーディング時
- プロジェクト全体像の把握が必要な時

## ワークフロー

### Step 1: ソースファイルのスキャン
全ソースファイルのインポート、エクスポート、依存関係をスキャン

### Step 2: コードマップ生成
以下の形式でトークン効率の良いコードマップを生成:

| ファイル | 内容 |
|---------|------|
| `codemaps/architecture.md` | 全体アーキテクチャ |
| `codemaps/backend.md` | バックエンド構造 |
| `codemaps/frontend.md` | フロントエンド構造 |
| `codemaps/data.md` | データモデルとスキーマ |

### Step 3: 差分計算
前バージョンからの差分パーセンテージを計算

### Step 4: 承認リクエスト
変更が30%を超える場合、更新前にユーザー承認をリクエスト

### Step 5: タイムスタンプ追加
各コードマップに鮮度タイムスタンプを追加

### Step 6: レポート保存
`.reports/codemap-diff.txt`にレポートを保存

## 出力例

```markdown
# Architecture Overview

## 更新日時
2024-01-24 10:30:00 JST

## プロジェクト構造
```
src/
├── app/           # Next.js App Router
├── components/    # UIコンポーネント
├── lib/           # ユーティリティ
├── hooks/         # カスタムフック
└── types/         # TypeScript型定義
```

## モジュール依存関係
[Mermaidダイアグラムまたはテキスト表現]

## 主要コンポーネント
- AuthProvider: 認証状態管理
- DataFetcher: APIデータ取得
- Layout: 共通レイアウト
```

## ベストプラクティス

1. **高レベル重視** - 実装詳細ではなく構造に焦点
2. **定期更新** - 大きな変更後に更新
3. **差分確認** - 30%以上の変更は確認
4. **TypeScript/Node.js使用** - 分析にはこれらを使用

## 成功指標

- コードマップが最新
- 構造が正確に反映
- 差分が適切に追跡
- タイムスタンプが更新
