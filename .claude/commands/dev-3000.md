# Dev: Comprehensive Development Support with MCP Integration

Advanced development support system combining dev3000's unified logging, Playwright's browser automation, and Serena's code intelligence for complete development workflow management.

## Usage Guide

### Basic Syntax
```bash
/dev [action] [target] [options]
```

### Available Actions

| Action | Description | Example |
|--------|-------------|---------|
| `logs` | View/analyze logs | `/dev logs --filter "ERROR"` |
| `errors` | Analyze browser errors | `/dev errors --last 1h` |
| `debug` | Debug specific issues | `/dev debug "login fails"` |
| `perf` | Performance analysis | `/dev perf --component Dashboard` |
| `e2e` | E2E testing | `/dev e2e --scenario login` |
| `screenshot` | Take screenshots | `/dev screenshot --selector #main` |
| `browse` | Browser automation | `/dev browse --action click --target #submit` |
| `analyze` | Code analysis | `/dev analyze --file auth.js` |
| `fix` | Automated fixes | `/dev fix --error "TypeError"` |
| `monitor` | Real-time monitoring | `/dev monitor --watch` |

### Core Options

| Option | Short | Description | Example |
|--------|-------|-------------|---------|
| `--watch` | `-w` | Real-time monitoring | `/dev logs -w` |
| `--filter` | `-f` | Filter by pattern | `/dev logs -f "ERROR"` |
| `--last` | `-l` | Last N entries | `/dev logs -l 100` |
| `--context` | `-c` | Context lines around match | `/dev errors -c 5` |
| `--fix` | | Attempt automatic fix | `/dev debug "auth error" --fix` |
| `--interactive` | `-i` | Interactive mode | `/dev debug -i` |
| `--record` | `-r` | Record session | `/dev e2e -r session.log` |
| `--analyze` | `-a` | Deep analysis with Serena | `/dev perf -a` |
| `--verbose` | `-v` | Detailed output | `/dev debug -v` |

## Workflow Processes

### Advanced Error Investigation Workflow
**For resolving: $ARGUMENTS**

1. **Unified Log Collection** (Dev3000 MCP)
   - Use `mcp__dev3000__read_consolidated_logs` to gather all application logs
   - Use `mcp__dev3000__get_browser_errors` for automatic error detection
   - Identify error patterns and timing with `mcp__dev3000__search_logs`

2. **Browser State Analysis** (Playwright MCP)
   - Capture current state with `mcp__playwright__browser_take_screenshot`
   - Take accessibility snapshot with `mcp__playwright__browser_snapshot`
   - Analyze network requests with `mcp__playwright__browser_network_requests`

3. **Code Context Investigation** (Serena MCP)
   - Find relevant symbols with `mcp__serena__find_symbol`
   - Trace dependencies with `mcp__serena__find_referencing_symbols`
   - Search for patterns with `mcp__serena__search_for_pattern`
   - Check previous solutions with `mcp__serena__read_memory`

4. **Strategic Analysis** (Sequential Thinking MCP)
   - Use `mcp__sequential-thinking__sequentialthinking` for systematic reasoning
   - Generate multiple hypotheses and test systematically
   - Build evidence-based solution approach

5. **Fix Implementation** (Serena MCP)
   - Apply targeted fixes with `mcp__serena__replace_symbol_body`
   - Use `mcp__serena__insert_before_symbol` for additional logging/validation
   - Store solution for future reference with `mcp__serena__write_memory`

6. **Validation** (Playwright MCP)
   - Verify fix with browser automation
   - Run targeted E2E tests
   - Capture proof of resolution

### Performance Optimization Workflow

1. **Performance Metrics Collection** (Dev3000 MCP)

2. **Code Analysis** (Serena MCP)
