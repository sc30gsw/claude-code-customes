# API Client (ky)

## `src/lib/api/client.ts` responsibility

This file owns all cross-cutting HTTP configuration. Keep it minimal.

Current defaults (from `client.setConfig`):

- `timeout`: 10 000 ms
- `retry.limit`: 2

Add auth headers or global error hooks here — not in individual feature API files:

```typescript
// src/lib/api/client.ts
import { client } from "./generated/client.gen";

client.setConfig({
  timeout: 10_000,
  retry: { limit: 2 },
  // Add auth header:
  // headers: { Authorization: `Bearer ${getToken()}` },
});
```

## Never edit `src/lib/api/generated/`

All files under `src/lib/api/generated/` are auto-generated by `vp run generate:api`. Any manual edits will be overwritten.

```
// WRONG: editing a generated file
// src/lib/api/generated/sdk.gen.ts ← DO NOT TOUCH

// CORRECT: regenerate when the OpenAPI spec changes
vp run generate:api
```

## Always wrap generated SDK in `features/*/api/`

Do not import from `sdk.gen.ts` directly in hooks or components. Wrap generated calls in a feature API module and return a `Result`:

```typescript
// features/products/api/products-api.ts
import { Result } from "better-result";
import { createProduct, getProducts } from "~/lib/api/generated/sdk.gen";
import type { CreateProductData, GetProductsData } from "~/lib/api/generated/types.gen";

export function fetchProducts(params: GetProductsData["query"]) {
  return Result.tryPromise({
    catch: (e) => e as Error,
    try: async () => {
      const { data } = await getProducts({ query: params });
      return data;
    },
  });
}

export function createProductApi(body: CreateProductData["body"]) {
  return Result.tryPromise({
    catch: (e) => e as Error,
    try: async () => {
      const { data } = await createProduct({ body });
      return data;
    },
  });
}
```
